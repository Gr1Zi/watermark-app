# watermark

Небольшое настольное приложение на Python для наложения изображения водяного знака на фотографию. Поддерживаются PNG с прозрачностью, настройка прозрачности и позиции, а также два режима смешивания.

## Возможности

- загрузка фонового изображения и водяного знака;
- размещение в одном из четырёх углов, по центру или по координатам;
- настройка общей прозрачности;
- ручное смешивание на NumPy или смешивание с использованием OpenCV;
- предварительный просмотр результата и сохранение в PNG, JPEG или BMP;
- автоматическое уменьшение водяного знака, если он больше фонового изображения.

## Требования

- Python 3.10 или новее;
- Windows, macOS или Linux с графическим окружением.

## Установка и запуск

```bash
git clone https://github.com/Gr1Zi/watermark-app.git
cd watermark-app
python -m venv .venv
```

Активируйте виртуальное окружение:

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```bash
# macOS / Linux
source .venv/bin/activate
```

Установите зависимости и запустите приложение:

```bash
python -m pip install -r requirements.txt
python watermark_app.py
```

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

## Использование

1. На верхней панели нажмите **Загрузить фон…**, затем **Загрузить водяной знак…**.
2. В области **Результат** перетащите знак левой кнопкой мыши или выберите готовое положение. Для варианта **Произвольно** задайте координаты X и Y в пикселях от верхнего левого угла.
3. Настройте прозрачность и при необходимости переключите режим смешивания.
4. Нажмите **Сохранить результат** или выберите этот пункт в меню **Файл**.

Для плавного контура водяного знака используйте PNG с прозрачным фоном. Если водяной знак крупнее фона, приложение уменьшит его с сохранением пропорций.
